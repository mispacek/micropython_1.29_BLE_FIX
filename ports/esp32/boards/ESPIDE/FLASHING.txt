ESP32 / ESP32-C3 / ESP32-C6 / ESP32-S3 MicroPython v1.29.0 BLE + Wi-Fi

Use the artifact for your chip. The complete firmware.bin includes the
bootloader, partition table and MicroPython application. Flash it at:

  ESP32_GENERIC (classic ESP32 / WROOM): 0x1000
  ESP32_GENERIC_C3, ESP32_GENERIC_C6, ESP32_GENERIC_S3: 0x0

Then reset the board. The classic ESP32 build requires at least 4 MB flash;
this artifact is the standard variant, without PSRAM support enabled.

For ESP32-S3, use SPIRAM_OCT only with Octal PSRAM. The standard build supports
Quad PSRAM and boards without PSRAM, following the upstream board defaults.

micropython.bin is the application ONLY. Its offset is 0x10000. It requires
the matching bootloader at the complete-image address listed above and the
partition table at 0x8000. Do not use it as a complete firmware image.

boot.py and main.py are separate filesystem files, not part of firmware.bin.
Reset the board to discard any temporary diagnostic monkey patches before
testing the new firmware. A complete flash erase is not required for this fix.

The ELF file is supplied for crash diagnosis and is not a flash image.
